# Lockboxes

## Description
This project contains a Python method to solve the "Lockboxes" interview problem.

## Requirements
- All files are interpreted on Ubuntu 14.04 LTS using `python3` (version 3.4.3).
- Code style follows `PEP 8` (version 1.7.x).
- All files must be executable.

## Tasks
### 0. Lockboxes
- Prototype: `def canUnlockAll(boxes)`
- Returns `True` if all boxes can be opened, else `False`.
